# Sistema de Logística para Dark Kitchens y Food Trucks

## Descripción

Sistema diseñado para gestionar y optimizar las operaciones logísticas de Dark Kitchens y Food Trucks.

El sistema permitirá administrar información relacionada con establecimientos, vehículos, productos, inventario, pedidos, rutas y entregas.

## Objetivo

Desarrollar una plataforma que facilite la administración y seguimiento de las operaciones logísticas de Dark Kitchens y Food Trucks.

## Funcionalidades principales

* Gestión de usuarios
* Gestión de Dark Kitchens
* Gestión de Food Trucks
* Gestión de productos
* Gestión de inventario
* Gestión de pedidos
* Gestión de entregas
* Gestión de rutas
* Seguimiento de operaciones
* Reportes y consultas

## Tecnologías


* Base de datos: MySQL
* Control de versiones: GitHub
* Gestión del proyecto: Jira
* Documentación: Confluence
